## ✅ 핵심 UX 개선 완료 (2026-04-08 진행)

**1. UX 흐름 개선 (adjust 화면 통합)**
- `page.tsx`: 'adjust' AppState를 제거하고 `result` 상태 안에서 `showAdjustPanel`을 통해 위치 조정 패널을 열고 닫도록 변경.
- 처리 완료 즉시 결과(result) 화면으로 진입하며, 다운로드 버튼 하단에 **"📐 위치 조정하기 (1회 무료)"** 버튼 배치.

**2. 모바일 터치 최적화 UI 적용**
- `globals.css`: 우측에 멀리 있던 세로 스크롤바를 뷰포트 하단으로 이동.
- 확대(Zoom), 가로 이동(X), 세로 이동(Y)을 조절하는 3개의 수평 Range Input을 세로로 스택하여 엄지 조작 범위 내에 집중.
- `max-height`를 이용한 부드러운 슬라이드 다운/업 아코디언 애니메이션 추가.

**3. 과금/결제 모델 UI 연동**
- `adjustUsed` 상태를 도입하여 첫 번째 위치 조정 렌더링 확인 시 패널이 닫히며 1회 차감되도록 구현.
- 사용 후 버튼이 **"📐 위치 조정하기 (추가 결제 준비 중)"** 상태로 전환되며 비활성화됨.
