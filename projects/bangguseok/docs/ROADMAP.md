# 방구석 사진관 (PassPro AI) — 제품 로드맵 (ROADMAP)

이 문서는 방구석 사진관의 과거(MVP), 현재, 그리고 미래의 발전 방향성에 대한 전체적인 마스터 플랜(Master Plan)을 정의합니다.

---

## 🎯 Phase 1: MVP 완성 및 Vibe Coding 최적화 (현재 상태)
**목표:** 최소 비용으로 최고의 퀄리티 여권/증명사진을 제공하는 WYSIWYG 에디터 구축 (달성 완)

- **핵심 기능 완료**
  - Next.js 16.2 스택 + Gemini API 연동 완료
  - AI 얼굴 인식 8개 조항 검증 및 백그라운드 색상 화이트(#FFFFFF) 처리
  - 드래그를 통합한 통합 반응형 WYSIWYG 에디터 오픈 (확대, 명도, 채도, 대비)
  - 이중 Rate-limit 해소 및 CSRF, 클릭재킹 방어를 통한 인프라 보안 안착
- **비즈니스 모델 (MVP 단계)**
  - 전면 **무료** 배포를 통한 사용자 데이터 수집 및 QA 개선 피드백 루프 생성

---

## 🚀 Phase 2: BM(수익 모델) 결합 및 성능 고도화 (Next Step)
**목표:** 월간 활성 사용자(MAU) 유치 및 결제 모듈 연동을 통한 수익화

- **기능 스코프**
  - **정밀 컨트롤러 추가:** 어깨 각도 조정기, 피부 잡티 세부 보정, 디지털 정장 슬라이더(AI 합성 추가).
  - **다국어 및 멀티 규격 지원:** 한국뿐 아니라 미국(2x2 inch), 일본 등 글로벌 여권 사진 템플릿 지원.
  - **디바이스 별 네이티브 호환성:** 모바일 앱 환경 최적화(PWA 적용)를 기반으로 한 빠른 렌더 속도 달성.
- **비즈니스 모델 설계**
  - **Freemium 전략:** 기본적인 규격 맞춤 및 밝기 조절 등은 무료 이용.
  - **Premium 결제 연동:** 정장 합성 서비스, 정밀 피부 보정, 고화질 모드 다운로드를 위한 1회 결제 시스템(Toss Payments / Stripe) 연동.

---

## 🌍 Phase 3: AI 기반 신분증 생태계 통합 및 B2B 확장 (Future)
**목표:** 단순 소비자용 B2C 툴을 넘어 스튜디오 및 기업들이 사용하는 B2B 컴포넌트로 확장

- **B2B API & SDK 배포**
  - 자체 여권사진 인증 로직이 필요한 기관이나 원서 접수처 등에 검증+크롭 파이프라인을 API로 제공.
- **고도화된 기능 (Enterprise & Extended)**
  - 다수 이미지 배치 프로세싱(한 번에 여러 직원 사진 렌더).
  - AI 생성 텍스트 기반 배경화면 교체(컬러 증명사진 트렌드 반영).
  - WebGL 기반 3D 조명 재조정(Relighting).
